# Lab 7.2: Marketing Channel ROI Comparison

## Overview
Statistical analysis of marketing channel performance across 3 competitive 
beauty brands (Nykaa, Tira, Purplle) to recommend $500K monthly budget 
allocation across 5 campaign channels.

## Approach
1. Loaded and combined 3 brand datasets (166,665 campaigns total)
2. Calculated key marketing metrics: CPA, ROAS, CTR, Conversion Rate
3. Performed pairwise statistical tests between all 5 channels
4. Applied multiple comparisons corrections (Bonferroni and FDR)
5. Conducted power analysis to validate data adequacy
6. Synthesized findings into actionable budget recommendations

## Key Findings
- No statistically meaningful CPA or ROAS differences between channels
- All channels perform within a narrow range (CPA: $2.02–$2.11)
- Dataset has sufficient power to detect differences of 5%+ if they existed
- Paid Ads ranks highest on composite score — recommended for largest allocation
- Fisher's test found statistical but not practical significance due to 
  massive sample size (150M+ clicks)

## Data
Download the dataset from Kaggle:
https://www.kaggle.com/datasets/sshriya08/multi-brand-marketing-campaign-performance-dataset

Place the 3 CSV files in the `/data` folder before running notebooks.

## Assumptions & Notes
- Dataset is synthetic — absolute values not suitable for financial planning
- Campaign_Type used as primary grouping variable (5 channels)
- Budget allocation based on composite score with 10-30% per channel constraints
- Power analysis uses 1,000 simulations per condition
